# Instruções de Fontes — Grid Marketing

Para utilizar as fontes licenciadas originais:
1. Adicione os arquivos das fontes nesta pasta:
   - `Canopee.woff2` ou `Canopee.ttf`
   - `EditorialNew-Regular.woff2` ou `EditorialNew-Regular.ttf`
   - `EditorialNew-Italic.woff2`
2. No arquivo `src/app/globals.css`, declare os blocos `@font-face` correspondentes apontando para `/fonts/...`.
3. Por padrão, o site utiliza alternativas gratuitas e de alta qualidade do Google Fonts:
   - Bebas Neue (Display)
   - Cormorant Garamond (Editorial)
   - Inter Tight (Interface)
